This release brings our bespoke kernel to everyone. The Omarchy kernel is tuned to keep the desktop responsive and multitasking smooth, even under heavy load or memory pressure. It improves gaming compatibility, enables smoother gaming on supported AMD HDMI displays, speeds up common Btrfs file operations, and refines power management. It also fixes everyday hardware frustrations, including missing audio, unresponsive touchpads, display freezes, and slow startup or resume on affected machines.

You can upgrade existing machines with Update > Omarchy.
