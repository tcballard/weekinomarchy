GitHub published v4.0.3 on September 8, 2026 and v4.0.4 on September 15, 2026. The paragraphs below are the opening text of those release notes. Checksums and the rest of each note are on the release pages.

## v4.0.3

This release brings amazing out-of-the-box integration for both Hermes and Openclaw as well as additional set of security fixes that were validated and examined by the Omarchy Security team. If you ever find security issues with Omarchy, please follow the responsible disclosure procedure on omarchy.org/security.

Upgrade existing machines with Update > Omarchy. The notes give the ISO as https://iso.omarchy.org/omarchy-4.0.3.iso and SHA256 `03d60bc74306dca51f96e1a84b690871d8d606826b260edd0208962da8507d14`.

[Release page](/releases/v4-0-3/) · [GitHub](https://github.com/omacom/omarchy/releases/tag/v4.0.3)

## v4.0.4

This release brings our bespoke kernel to everyone. The Omarchy kernel is tuned to keep the desktop responsive and multitasking smooth, even under heavy load or memory pressure. It improves gaming compatibility, enables smoother gaming on supported AMD HDMI displays, speeds up common Btrfs file operations, and refines power management. It also fixes everyday hardware frustrations, including missing audio, unresponsive touchpads, display freezes, and slow startup or resume on affected machines.

Upgrade existing machines with Update > Omarchy. The notes give the ISO as https://iso.omarchy.org/omarchy-4.0.4.iso and SHA256 `ddeded2758c48318d201dfdac905ecb28f570441883f0c052ea3cd5d05acf92d`.
